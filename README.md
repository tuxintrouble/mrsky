# mrsky
MRSKY allows to connect a regular morse paddle to a serial interface (as used with SigBit https://github.com/tuxintrouble/sigbit) and generate keyboard strokes as they are used with VBand (https://hamradio.solutions/vband/)

Edit the script mrsky.py to configure it to use the proper Serial port and keyboard keys.

##dependencies
python3
pyserial
pynput
